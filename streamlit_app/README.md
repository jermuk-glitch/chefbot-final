# 🍳 ChefBot — кулінарний асистент у Streamlit

Практична робота до теми 10: перенесення агента з теми 8 у вебінтерфейс.

## Структура

```
chefbot/
├── app.py                 # інтерфейс Streamlit
├── agent.py               # агент LangGraph + Gemini і три інструменти
├── requirements.txt
├── UX_AUDIT.md            # шаблон UX-аудиту
└── .streamlit/
    └── secrets.toml       # ваш API-ключ (не публікувати!)
```

## Запуск

```bash
pip install -r requirements.txt
```

Відкрийте `.streamlit/secrets.toml` і вставте свій ключ Gemini:

```toml
GOOGLE_API_KEY = "ваш-ключ"
```

Потім:

```bash
streamlit run app.py
```

Застосунок відкриється в браузері за адресою http://localhost:8501.

## Як підключити власного агента з теми 8

`app.py` звертається лише до двох функцій з `agent.py`:

- `build_agent(api_key)` повертає готового агента;
- `stream_reply(agent, history, fridge, diet, tool_results)` віддає текст відповіді по шматочках.

Замініть інструменти та `build_agent()` своїми. Якщо ваш агент створений
через `create_react_agent` (LangGraph), `stream_reply()` працюватиме без змін.

## Що реалізовано

| Вимога | Як зроблено |
|---|---|
| Чат | `st.chat_message()` + `st.chat_input()` |
| Історія | `st.session_state.messages`, у модель іде вікно з 12 останніх повідомлень |
| Sidebar впливає на агента | холодильник і обмеження щоразу передаються в system prompt |
| Індикатор обробки | `st.spinner()` + стрімінг через `st.write_stream()` |
| Спецкомпоненти | `st.multiselect()`, `st.checkbox()`, `st.container(border=True)`, `st.expander()` |
| Розширення | список покупок із відсутніх інгредієнтів, швидкі кнопки-підказки |

## Деплой на Streamlit Community Cloud (за бажанням)

1. Завантажте папку в репозиторій GitHub (файл `secrets.toml` уже в `.gitignore`).
2. На share.streamlit.io створіть застосунок, вкажіть `app.py`.
3. У налаштуваннях застосунку → **Secrets** вставте рядок `GOOGLE_API_KEY = "..."`.


## База рецептів

- `agent.py` — базові рецепти прототипу.
- `recipes_saved.json` — 24 рецепти, перенесені з рецептів-постерів, які я зберегла (паста з креветками, лосось, форель, голубці, тефтелі, синабони, суфле-панкейки та ін.). Файл підвантажується автоматично; щоб додати рецепт, допишіть об’єкт у той самий формат (`ingredients` — короткі назви для пошуку, `amounts` — точні кількості для картки).
- Міри: склянка = 250 мл, американська cup = 240 мл; густини збігаються з ноутбуком (2 склянки борошна = 265 г, 2 cup = 254,4 г). Додано перетворення °F ↔ °C.
