# UX-аудит ChefBot

> Заповніть після запуску з реальним ключем. Колонка «Очікування» вже заповнена,
> у колонку «Що сталося» впишіть власні спостереження.

## 1. Тестові сценарії

| # | Запит | Налаштування sidebar | Очікування | Що сталося |
|---|---|---|---|---|
| 1 | Що можна приготувати з курки та картоплі? | холодильник порожній | бот викликає `recipe_search`, над чатом з'являються картки | |
| 2 | Що приготувати з того, що є в холодильнику? | курка, картопля, цибуля | бот бере інгредієнти з sidebar, не питаючи їх у чаті | |
| 3 | Скільки грамів борошна в одній склянці? | — | ≈ 125 г через `unit_converter`, а не «з голови» | |
| 4 | Чим замінити яйця у випічці? | — | 2–3 варіанти через `substitution_finder` | |
| 5 | Запам'ятай, що я не їм глютен — і знайди рецепт без глютену | прапорець «Без глютену» вимкнено | бот шукає без глютену й радить увімкнути прапорець | |
| 6 | Той самий запит, що в №2 | увімкнено «Вегетаріанське» | у картках лише вегетаріанські страви | |

## 2. Що стало зручніше порівняно з консоллю

- Інгредієнти й обмеження задаються один раз і діють у кожній відповіді.
- Рядок «Холодильник / Обмеження» над чатом показує, що саме бачить агент.
- Рецепти показано картками: час, теги, інгредієнти з позначками ✅/🛒, кроки в expander.
- Швидкі кнопки на старті: не треба вигадувати перший запит.
- Відсутні інгредієнти одним натиском потрапляють у список покупок.
- Відповідь з'являється поступово, тож видно, що система працює.

## 3. Нові ризики, які з'явилися в UI

- **Розбіжність стану.** Сценарій 5: користувач просить «запам'ятати» в чаті, але прапорець
  у sidebar лишається вимкненим. Пам'ять діалогу й налаштування інтерфейсу можуть розійтися.
- **Довіра до карток.** Агент може пропустити прапорець обмеження під час пошуку. У застосунку
  додано страховку: картки повторно фільтруються за активними обмеженнями.
- **Сценарій «руки зайняті».** На телефоні sidebar ховається, тож холодильник не видно
  під час готування. Варто перевірити зручність на вузькому екрані.
- **Втрата стану.** Після перезавантаження сторінки зникають чат, холодильник і список покупок.

## 4. Що доопрацювати далі

- Синхронізувати «запам'ятай» із прапорцями sidebar (бот сам вмикає обмеження).
- Зберігати холодильник і список покупок між сесіями.
- Додати режим «крок за кроком» для приготування з великими кнопками.
